# Target constructor quotation fixture

This separate opt-in hosted candidate exercises the actual QuoteTarget instances
and constructor printer on22 small fixed case lists. It proposes44 independently
consumed value/type equalities,a strict two-primary-owner audit against standard
three axioms,nine typed mutations and a weak-True fixed-consumer refusal.
Actual producer output,Kernel and negative results remain pending.

Cases cover every current manual/derived constructor and payload slot,with
unequal field sentinels,high-bit and all-ones64-bit words,byte0/128/255,nested
Spt shapes,all comparison/memory operators and distinct line position/encoded
bytes/length. Finite coverage is not a universal quotation theorem.

The dedicated branch-push/manual workflow preserves upstream-only cache setup.
It requires a fresh entire project namespace,pins the full SOURCE graph and
configuration/provider bytes,then builds only Cases and Produce prerequisites.
The actual producer runs twice in distinct new canonical roots. Their single
output files must match byte-for-byte and pass exact command/obligation and
anti-alias guards. These lexical guards supplement the independent Kernel
consumers;they do not parse Lean or certify terms by themselves.

Replay uses a new complete project namespace containing only Cases,Output,
FixedChecks and Audit. Ordinary project source/object fallback is removed;
all first-provider dependency sources,objects and import companions are pinned.
Source,SDK selection/binary/version,prepared packages,aliases,generated sources,
prior artifacts and complete materials are rechecked before final atomic PASS.
A producer or failed proof cannot create an accepted partial batch.

The driver is serial and bounded:60seconds per producer,180seconds per positive
leaf,120seconds per negative/header batch,and3600seconds for cold prerequisites.
Each proof/producer/header/build leaf has a private process group,drained while its leader remains owned,
and a4MiB per-file limit (16MiB header JSON;64MiB cold build files). Lean
-M4096 bounds Lean's managed allocation and is not an RSS/host memory guarantee.
The workflow's runtime-thread setting is a request;resource fit is unmeasured.
Artifacts are explicit sources,logs,reports and five selected proof objects;
no runtime mirror,IR,native binary,captured target or broad build cache is uploaded.

This fixture does not quote the function-bearing16-field assembler config.
It proves no encoder/config equality,Native-output binding,actual target context,
alignment,final byte identity or resource/deployment certificate. Config projection
and ORIGINAL LowerInput/config Kernel bindings remain separate prerequisites to
any future context capture. The callable context writer is never invoked here.
